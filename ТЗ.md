# ТЗ: «По сусекам» — рецепты из того, что есть в холодильнике

**Автор:** Диана Пейкришвили · **Статус:** MVP, работает в проде · **Дата:** 30.09.2026

- Живая версия: https://po-susekam.pages.dev
- Код: https://github.com/DinaPeikr/po-susekam

## 1. Задача

Человек открывает холодильник и не знает, что приготовить из того, что есть. Искать рецепты по одному продукту
неудобно, а готовые подборки требуют докупать половину списка.

**Решение:** пользователь перечисляет продукты (текстом, голосом или фото), а приложение предлагает
шесть блюд именно из них. У каждого блюда видно время, калории на порцию и чего не хватает. Дальше можно готовить
по шагам с таймерами.

**Для кого:** домашняя кухня, с телефона и с ноутбука. Регистрация не нужна.

## 2. Границы MVP

**Входит** — полный путь пользователя «продукты → выбор блюда → приготовление»:

| № | Функция | Что должно работать |
|---|---|---|
| 1 | Ввод продуктов текстом | Чипсы: запятая или Enter добавляют, Backspace удаляет последний, дубли отсекаются, максимум 30 |
| 2 | Ввод по фото | Снимок полки → Claude распознаёт продукты и дописывает их в поле |
| 3 | Ввод голосом | Во всех браузерах: Web Speech (Chrome, Edge, Safari), запись + Whisper на сервере (Firefox, Brave) |
| 4 | Подбор рецептов | 6 блюд за запрос: название, описание, время, порции, ингредиенты, шаги, совет, «чего не хватает» |
| 5 | Ещё рецепты | Ещё 6 блюд без повторов; всего 2 раунда (12 рецептов), потом понятное сообщение о лимите |
| 6 | Калории | Считает сервер: сумма калорий ингредиентов / порции (модель «на глаз» занижает на треть) |
| 7 | Фото блюд | Unsplash, запасной — Pexels; у карточек не бывает одинаковых фото; подпись автора |
| 8 | Страница рецепта | Фото, плашки (время, порции, ккал, чего не хватает), ингредиенты, шаги, совет, поиск видео на YouTube |
| 9 | Пошаговый режим | Один шаг на экран, иконка и таймер по тексту шага, несколько таймеров сразу, сигнал и вибрация, экран не гаснет |
| 10 | Избранное | Сохранение в браузере (до 100 рецептов), синхронизация вкладок |
| 11 | Несъедобное | «Бумага, клей, сыр» → рецепты из сыра; «камни, песок» → честный пустой ответ |

**Не входит в MVP** (кандидаты на следующие версии): аккаунты и синхронизация избранного между устройствами,
фильтры (вегетарианское, без глютена), список покупок из «не хватает», оплата и платные функции.

## 3. Нефункциональные требования

- **Адаптив:** от 390 px (телефон) до ноутбука 1536×730 без горизонтального скролла; вёрстка по макету из Figma.
- **Скорость:** подбор — медиана ≈ 24 с; пока ждём — скелетоны карточек и подсказка «обычно 15–25 секунд».
- **Стоимость:** один подбор ≈ $0,018 (≈ 1 000 входных и 2 200 выходных токенов); диктовка — $0,0005 за минуту.
- **Безопасность:** ключи API только на сервере, в браузер не попадают.
- **Устойчивость:** обработаны отказ модели, обрыв по лимиту токенов, 429 и 502; фото кэшируются на сутки;
  если Unsplash отказал — Pexels; если отказали оба — карточка с градиентом вместо фото.
- **Состояние:** продукты и найденные рецепты переживают F5 и переход на рецепт (sessionStorage).

## 4. Архитектура

```
Vue 3 + Vite  ── /api/* ──►  Cloudflare Pages Functions  ──►  Claude API (claude-sonnet-5)
                                                          ──►  Unsplash / Pexels
                                                          ──►  Workers AI (Whisper)
```

| Эндпоинт | Вход → выход |
|---|---|
| `POST /api/recipes` | `{ ingredients, exclude? }` → 6 рецептов по JSON-схеме (structured outputs), `canLoadMore` |
| `POST /api/recognize` | фото `{ image, mediaType }` или фраза `{ text }` → `{ ingredients }` |
| `POST /api/transcribe` | аудио (webm / ogg / mp4) → текст через Whisper |
| `GET /api/photo?q=` | фото блюда из Unsplash или Pexels, кэш на сутки |

Стек: Vue 3 (Options API), Vue Router, Vite, SCSS; Cloudflare Pages Functions; Claude API; Workers AI;
Unsplash и Pexels API.

## 5. Приёмка: чем проверено

- **Evals для подбора рецептов:** 18 кейсов × 3 запуска, 13 автоматических проверок кодом (ровно 6 рецептов,
  калории по каждому ингредиенту, в «не хватает» нет продуктов пользователя, блюда не повторяются и др.).
  Первый прогон нашёл баг, который вручную не находился: «бумага, клей, сыр» давали пустой ответ в 5 из 6
  запусков. После правки промпта — 5 из 5.
- **Evals для распознавания:** 12 фраз и 2 фото — **201 из 201** проверок.
- **Вёрстка:** скриншоты в headless Chrome на 1536 и 390 px, проверка горизонтального перелива.
- **Голос:** три автоматических сценария — запись, браузер Brave, тишина.
- **Прод:** задеплоен на Cloudflare Pages; 30.09.2026 подбор на живой версии вернул 6 рецептов за 27 с.
