# По сусекам — рецепты из того, что есть в холодильнике

Интерфейс и все тексты — на русском. Код — Vue 3 **Options API**, Vite, SCSS. Комментарии в коде — по-русски, объясняют «почему».

## Архитектура
Vue 3 + Vite ── /api/* ──► Cloudflare Pages Functions (functions/api/*.js) ──► Claude API / Unsplash
- Один Pages-проект: фронт в dist/, функции рядом. Локально: `npm run dev` (Vite 5173, proxy /api → 8788)
  и `npm run dev:api` = `wrangler pages dev --port 8788` (перед первым запуском `npm run build`).
- wrangler.toml: name = "po-susekam", pages_build_output_dir = "dist", compatibility_flags = ["nodejs_compat"],
  [vars] RECIPES_COUNT = "6", SEARCH_ROUNDS = "2" (поиск + одно «Ещё рецепты» = 12 рецептов и 12 фото — бережём лимит Unsplash). Секреты — .dev.vars (в .gitignore вместе с .wrangler).
- Модель: `claude-sonnet-5`, `output_config: { effort: 'low', format: { type: 'json_schema', schema } }`.
  Логировать `response.usage`. Обработать refusal, max_tokens, RateLimitError (429), APIError (502).
- Зависимости: vue, vue-router, @anthropic-ai/sdk; dev: vite, @vitejs/plugin-vue, sass, wrangler.

## API
### POST /api/recipes  { ingredients: string[], exclude?: string[] }
- Системный промпт: шеф домашней кухни, «Предложи ${RECIPES_COUNT} разных блюд — от простых и быстрых до чуть более
  интересных»; соль/перец/масло/вода/сахар всегда есть; missing — чего не хватает; шаги без нумерации;
  image_query — 2–4 слова по-английски; ingredient_calories — ккал каждого пункта ingredients в том же порядке
  (макароны/крупы/мука по сухому весу, соль/специи/вода — 0); несъедобное рядом со съедобным молча пропустить
  и готовить из остального (даже если съедобный один); пустой recipes — только если съедобного нет совсем.
  (Проверено evals 29.09: со старым «нет съедобного — пустой» «бумага, клей, сыр» давали пустой ответ в 5 из 6.)
- JSON-схема рецепта (порядок полей ВАЖЕН — модель пишет по порядку): title, description, time_minutes, servings,
  ingredients, ingredient_calories, missing, steps, tip, image_query. additionalProperties: false.
- Калории на порцию считает СЕРВЕР: сумма ingredient_calories / servings, округлить до 10 → calories_per_serving.
  (Модель на effort low складывает на глаз и занижает на треть.)
- exclude — названия уже показанных блюд: «Эти блюда я уже видел, предложи другие…».
- Лимит раундов: round = floor(exclude.length / count) + 1; если round > SEARCH_ROUNDS → 429 { limitReached: true }
  без вызова Claude. Ответ: { recipes: recipes.slice(0, count), canLoadMore: round < SEARCH_ROUNDS }.
### POST /api/recognize  { image, mediaType } | { text }
- Фото (jpeg/png/webp/gif, ≤5 МБ base64) или продиктованная фраза (≤1000 символов) → { ingredients: string[] }.
  Общие правила: по-русски, нижний регистр, общие названия, без количества, не выдумывать.
  Для текста: «распознано автоматически, без препинания и с ошибками — исправь явные ошибки».
### GET /api/photo?q=
- Сначала Unsplash search/photos (per_page 5, orientation landscape, content_filter high, запрос `${q} food`),
  если отказал или пусто — Pexels /v1/search (per_page 5, orientation landscape, заголовок Authorization: ключ).
  Ответ { photos: [{ id: 'unsplash-…'|'pexels-…', raw, alt, author, authorUrl, sourceName, sourceUrl }] };
  у Unsplash — utm_source в ссылках, у Pexels sourceUrl = страница фото. Ресайз у обоих параметрами ссылки.
  Кэш caches.default на сутки. Нет ключей → { photos: [] }. Оба отказали → 503, НЕ кэшировать.
- Клиент берёт первое фото, чей **id** (не raw — в raw свой ixid) не занят другими карточками. При ошибке
  photoStatus остаётся idle — догрузится при следующем заходе. Размер через параметры raw: w, h, fit=crop, q=75.
- Подпись на странице рецепта «Фото: автор / Unsplash|Pexels» со ссылками — обязательна по правилам обоих.

## Фото и голос на клиенте
- prepareImage: createImageBitmap → canvas ≤1568px → JPEG 0.85 → base64 + превью. HEIC не открылся —
  «Попробуйте JPG или PNG». После выбора файла event.target.value = ''.
- Голос — гибрид, вся логика в `src/utils/speech.js`: `listen({ lang, onInterim, onProcessing }) → { result, stop(), abort() }`.
  Web Speech (`SpeechRecognition || webkitSpeechRecognition`, ru-RU, continuous + interimResults) там, где работает
  (Chrome, Edge, Safari). Нет Web Speech (Firefox) или он упал с `network` при `navigator.onLine` (Brave) →
  запись MediaRecorder (webm/ogg/mp4) → `POST /api/transcribe` (байты аудио) → Whisper `@cf/openai/whisper-large-v3-turbo`
  на Workers AI (binding `[ai] AI` в wrangler.toml, `vad_filter: true`) → текст → `/api/recognize` с `{ text }`.
  Тишина при записи — AnalyserNode, RMS > 0,02; стоп через 2,5 с тишины после речи, 8 с без речи — «Ничего не услышали»
  без запроса, максимум 20 с. `?voice=record` — принудительно запасной путь. Статус «Распознаём речь…» пока ждём Whisper.
  Повторное нажатие — «Готово». Во время записи микрофон rust с пульсацией, остальное заблокировано.
  Проверка: `scripts/voice-check.mjs` (запись, заглушка Brave, тишина).

  На последнем шаге — совет.

## Грабли Windows
- curl из Git Bash портит кириллицу в -d → JSON только из UTF-8 файла через --data-binary @file.
- Python print кириллицы → PYTHONIOENCODING=utf-8.
- Остановка wrangler не всегда убивает workerd.exe: порт 8788 занят, запросы висят. Проверка:
  Get-NetTCPConnection -LocalPort 8788; останавливать всё дерево (node wrangler + workerd).
- После правки .dev.vars или wrangler.toml — перезапуск `npm run dev:api`.
- Unsplash Demo — 50 запросов/час: на тестах кончается быстро (403 remaining 0).
- Расширение Chrome не снимает скриншоты свёрнутого окна — использовать headless Chrome + CDP (Node, global WebSocket).
  Скриншот с прокруткой — без clip (clip в координатах документа).
- Vue срезает ведущий пробел в `<span> {{ x }}</span>` → `&nbsp;{{ x }}`.
